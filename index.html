Démarrer l'essai

Prêt en deux minutes

Téléchargez l'installateur, puis activez l'essai depuis le logiciel. Aucune carte bancaire n'est demandée.

Télécharger TGM pour Windows

Windows 10 ou 11, 64 bits. Une connexion Internet pour l'activation.

Windows affiche « Éditeur inconnu » ?

C'est normal pour un logiciel indépendant. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». L'installateur provient de la page officielle des versions de TGM sur GitHub.

  1. Installez TGMLancez l'installateur téléchargé et suivez les étapes.
  2. Démarrez l'essaiÀ l'ouverture, cliquez sur « Essai gratuit 14 jours ».
  3. Ouvrez un fichierGlissez votre .bin dans la fenêtre : l'identification démarre seule.
  4. Gardez votre travailÀ l'achat, votre clé s'affiche aussitôt : entrez-la dans Aide, Activation. Vos projets restent en place.
